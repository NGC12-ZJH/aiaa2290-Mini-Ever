# 实验协议与记录规范

此文件补充 README 的实施约定，所有阈值和超参数应在正式运行前固定。

## 数据隔离

- 固定身份筛选、身份内划分、整数舍入规则和随机种子；保存本地 manifest 与哈希。
- 训练、gallery、测试和重新学习样本不得无意重叠。示踪仅修改指定训练样本，保留干净对照。
- 系统照片库与受控审计集合分开，删除操作限制在实验副本内。
- LFW 去重后报告保留的身份、正负对数量和评估协议；不把修改后的基准称为原始 6,000 对结果。
- 蒸馏集不含遗忘身份；量化校准集来源必须固定并记录。
- 公开池与用户池按身份划分并固定；公开池身份永不进入遗忘组，公开基础模型训练时不得接触用户池任何样本。
- 上传账户分配（本人账户比例、其他上传者数量）按固定种子生成并保存哈希；只作用于训练照片，gallery、测试与审计样本不随账户删除而改变。
- 每个产物版本记录所含账户与身份集合及其哈希；删除请求的影响范围以该清单为准。
- 实验 4b 的遗漏照片按 `r`、遗忘组和种子固定抽样，各 `r` 共享同一遗忘组，以便比较。

## 对照与公平性

每个遗忘组、模型架构、分片设计和随机种子关联对应的 never-trained 参照。排除遗忘身份后从同一公开基础模型重新进行第二阶段训练，记录训练配方及数据顺序。参照分两种：人物参照排除遗忘身份的全部训练照片，是所有“遗忘”结论的默认基准；账户参照只排除本人账户照片，仅用于检验账户删除是否执行正确，不能用来声称已忘记此人。SISA 的参照沿用相同分片方案，不重新随机分片。

顺序删除实验必须累计排除已删除身份，更新所有相关产物的版本。区分单次删除耗时、累计重训耗时、初次建模成本和全链路更新成本。GPU 计时应同步设备，记录硬件、精度、软件版本与峰值显存。

L1 的分类头及标签空间在重训前后可能不同，需预先明确屏蔽、删除类别和匹配身份的比较协议。Gallery 检索需区分“固定注册协议下的诊断测试”和“实际清除 gallery 后的系统状态”。删除 gallery 后不可将无法查询简单解释成参数已遗忘。

## 统计与结论

每个指标记录原值、参照值、差值和不确定区间。报告不同遗忘组与随机种子的波动，避免把同一身份的多张照片当作完全独立重复。

预先登记等效界值、置信水平、检验方法、多重比较规则、攻击访问权限和超参数选择范围。使用“通过／失败／不确定／不适用”四种状态。未检出显著差异不能单独构成等效证明。

U-LiRA 必须记录影子模型数量、in/out 抽样和攻击拟合流程。单纯比较样本 loss 的版本标记为简化基线。INT4 后端不可用时记录 N/A，不生成模拟结果。

实验 4 在比较不同节点前统一攻击优势的含义、方向和尺度，单独记录参照的攻击性能。T/D/M 的评分规则应独立于观测结果制定；若无法合理量化，采用定性环节标签和定量节点泄露，避免硬造平均分。
